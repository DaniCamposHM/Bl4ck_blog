# BL4CKJACKHM

Blog personal de cybersecurity — investigacion, practica y documentacion tecnica.

Escrito para aprender en publico y dejar evidencia de lo estudiado. Articulos, guias, writeups de labs, notas sobre Linux, y la interseccion entre videojuegos y seguridad informatica.

## Proposito

Compartir hallazgos, investigaciones y tutoriales de lo que voy aprendiendo y descubriendo. La idea no es parecer una "pagina hacker", sino mostrar trabajo real de alguien que estudia, investiga y practica cybersecurity.

> "Esto se" + "Aqui esta la evidencia."

## Stack

- **Astro** — generador estatico
- **React** — interactividad puntual
- **Tailwind CSS** — estilo
- **Markdown** — formato de contenido
- **Obsidian** — edicion
- **Netlify** — hosting
